## Description
Diagram3D is a client-side Minecraft mod that visualizes the force vectors from
**Create Aeronautics' Contraption** Diagram directly in the Minecraft world.

Instead of interpreting the diagram as a 2D representation, 
Diagram3D displays the forces as 3D vectors at their actual positions, 
making their direction, location, 
and overall behavior much easier to understand at a glance.

## Features
- Visualizes Contraption Diagram force vectors directly in the world
- Displays vectors in 3D at their corresponding positions
- Makes force direction and distribution easier to understand
- Client-side — no server installation required

- ## Troubleshooting
If you encounter visual bugs or unexpected behavior, try resetting Diagram3D's data:

`/diagram3d debug reset`
