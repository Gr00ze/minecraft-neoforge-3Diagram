# Changelog

## V0.2.0 — Force Group Display, Mass Display, Keybind

- Added rendering for force group information.
- Added rendering for mass information.
- Increased the rendered line size.
- Added a configurable `V` keybind to enable or disable the mod.
- Added logic to enable rendering in Creative and Spectator modes, or in Survival mode while wearing goggles.

## V0.1.3 — Keybind

- Added a configurable `V` keybind to enable or disable the mod.
- Added logic to enable rendering in Creative and Spectator modes, or in Survival mode while wearing goggles.

## V0.1.2 — Mass Display

- Added rendering for mass information.
- Increased the rendered line size.

## V0.1.1 — Force Group Display

- Added rendering for force group information.

## V0.1.0 — Bug Fix

- Added `/diagram3d debug reset` to reset the packet management state in case of an error.
- Fixed a bug in packet management that prevented rendering from being displayed.
- Made the detection range for sublevels (contraptions) configurable.
- Added an in-game configuration option to disable the mod.

## V0.0.1 — Initial Version

- Added persistent in-world rendering of vectors.
