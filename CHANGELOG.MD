# Changelog

## V1.0.1 — Hotfix render stutter

- Fixed render stutter of every moving graphic element

## V1.0.0 — Release

- Fixed some alignment issues in the custom config screen
- Added an option to enable a background texture for the force and mass displays
- Added an option to enable a background texture for the custom config screen
- Added configuration options to set background colors for the displays and custom config screen
- Added an option to select the vector style: Slim or Textured

## V0.4.0 — Display on look - Merged Forces, Outline, Vector scaling configuration

- Added option to visualize merged or separated forces
- Added an outline to make vectors more visible
- Added a configuration option to enable or disable the outline
- Added configuration options to scale vector dimensions proportionally and quadratically
- Added a button shortcut to open the configuration screen
- Made more options translatable
- Changed vector scaling configuration maximum limits
- Added a detailed description of the scaling function
- Added a dynamic "Details on Look" option for the center of mass
- Added a "Details on Look" option for all force group information
- Added automatic positioning for force group details when "On Look" is enabled

## V0.3.2 — Merged Forces, Outline, Vector scaling configuration

- Added configuration to set merged forces diagrams like.
- Added an outline to make vectors more visible
- Added a configuration to make outline optional
- Added configuration to scale proportionally and quadratically the vector dimension
- Added a button shortcut to open configs
- Now more options are translatable
- Changed configuration to scale maximum limits
- Added a detailed description of the scaling function

## V0.3.1 — Display on look

- Added details on look option for center of mass
- Added details on look option for all force group information.
- Added auto positioning for force group details when set to on look

## V0.3.0 — Toggle Message, Bug Fixes, New Menu, Center of Mass Icon

- Added an enable/disable message.
- Fixed a rendering issue where some info backgrounds were not displayed.
- Fixed an issue where info elements were rendered behind solid blocks.
- Added a custom config menu, accessible by pressing the toggle key, to select which force group information to display.
- Added a simpler way to display the center of mass.
- Added a configuration persistency for the custom menu
- Added more translations

## V0.2.0 — Force Group Display, Mass Display, Keybind

- Added rendering for force group information.
- Added rendering for mass information.
- Increased the rendered line size.
- Added a configurable `V` keybind to enable or disable the mod.
- Added logic to enable rendering in Creative and Spectator modes, or in Survival mode while wearing goggles.

## V0.1.3 — Keybind

- Added a configurable `V` keybind to enable or disable the mod.
- Added logic to enable rendering in Creative and Spectator modes, or in Survival mode while wearing goggles.

## V0.1.2 — Mass Display

- Added rendering for mass information.
- Increased the rendered line size.

## V0.1.1 — Force Group Display

- Added rendering for force group information.

## V0.1.0 — Bug Fix

- Added `/diagram3d debug reset` to reset the packet management state in case of an error.
- Fixed a bug in packet management that prevented rendering from being displayed.
- Made the detection range for sublevels (contraptions) configurable.
- Added an in-game configuration option to disable the mod.

## V0.0.1 — Initial Version

- Added persistent in-world rendering of vectors.
